# نقشه راه رستا (Rasta Roadmap)

> سند تصمیمات فنی — با پیشرفت پروژه به‌روز می‌شود

## اهداف محصول

- CRM تجاری بالغ: سبک، مدرن، فارسی/RTL-First
- حذف کامل میراث نسخه قدیمی (۹ jQuery، دو نسل Kendo، Bootstrap ناتمام، سه کتابخانه نمودار موازی)
- امنیت از روز اول — بدون تکرار بدهی‌های CRMIdeal
- آماده برای SaaS/چند-مستأجری در آینده

## پشته فناوری (تصمیم نهایی — پیاده‌سازی‌شده)

| لایه | انتخاب رستا | جایگزینِ قدیمی |
|---|---|---|
| زبان | TypeScript (سرتاسر استک) | C# / .NET FW 4.7 |
| فریم‌ورک | Next.js 16 App Router | ASP.NET MVC 5 |
| API | Route Handlers (REST) | Web API 2 |
| ORM | Prisma (code-first + مهاجرت) | EF5 Database-First (۷ EDMX!) |
| دیتابیس | SQLite (توسعه) → PostgreSQL (استقرار) | SQL Server |
| UI | Tailwind 4 + shadcn/ui — RTL، وزیرمتن | Kendo ×۲ نسل + Bootstrap 3/4 |
| نمودار | Recharts | Highcharts + Chart.js + CanvasJS |
| Auth | jose JWT + کوکی HttpOnly + scrypt | SimpleMembership |
| تقویم | جلالی بومی (`src/lib/jalali.ts`) | تقویم شمسی/قمری jQuery |

## نگاشت هسته دامنه (CRMIdeal → رستا)

| نسخه قدیم | رستا (MVP فعلی) |
|---|---|
| CrmCompany / CompanyPersons | Company / Contact |
| CrmProjects (فرصت‌ها) | Deal (کانبان فروش) |
| WSOrder / WSPreOrder | SalesOrder / Quotation (+ Payment) |
| Rolls / UsersPermission | Role / RolePermission (ماتریس دسترسی) |
| Cartables | Tasks کارتابل + Activities |
| Setting Area | Setting |

## وضعیت فازها

- ✅ **فاز ۰ — زیرساخت:** مخزن گیت (main + develop)، دیکامپایل کامل ۸ اسمبلی (~۹ هزار فایل)، مستندات
- ✅ **فاز ۱ — هسته CRM (MVP):** Auth + RBAC، داشبورد KPI، شرکت‌ها، مخاطبین، فرصت‌ها (کانبان)، فعالیت‌ها، کارتابل وظایف، محصولات، پیش‌فاکتور→سفارش، پرداخت، کاربران/نقش‌ها، گزارش‌ها، داده دموی فارسی — E2E تست‌شده
- ⬜ **فاز ۲ — انبار و خرید:** موجودی، انبار، سفارش خرید (پورت از Area های WareHouse/BuyOrders/StockSupply)
- ⬜ **فاز ۳ — مالی:** خزانه، بانک، پرداخت آنلاین (ملت/پارسیان/زرین‌پال)
- ⬜ **فاز ۴ — ارتباطات:** پیامک (۱۵+ درگاه)، ایمیل، ربات تلگرام
- ⬜ **فاز ۵ — منابع انسانی:** مرخصی، حاضری (QR)، مکان‌یابی GPS
- ⬜ **فاز ۶ — گزارش‌ساز پیشرفته + فرم‌ساز پویا (DyForms)**
- ⬜ **فاز ۷ — یکپارچه‌سازی مالی (سپیدار/هلو/...) + سامانه مودیان**
- ⬜ **فاز ۸ — ماژول AI:** مدیریت Providerهای LLM، کتابخانه Prompt، سهمیه Token کاربران
- ⬜ **فاز ۹ — سخت‌سازی، تست‌های خودکار، داکر و انتشار اولیه**

## به‌تعویق‌افتاده (تصمیم مالک پروژه)

- 🔐 **رمزنگاری/لایسنس‌گذاری محصول** — بعد از انتشار اولیه با طرح قوی‌تر پیاده می‌شود. معادل آن در نسخه قدیم (`RegisterCompany.dll`) فعلاً فقط به‌عنوان مرجع دیکامپایل شده است.

## سیاست توسعه

- تمام توسعه روی شاخه `develop` کامیت و پوش می‌شود
- شاخه `main` فقط با تأیید مالک برای انتشار اولیه از `develop` ادغام خواهد شد
