## ۵) پوشش‌های رفتاری خاص (نه فقط HTTP)

- **پیام‌های فارسی عین منبع**: هر پیام ادعاشده در تست از satellite fa-یر استخراج شده (روش: `scripts/dotnet_resx.py`) — هیچ پیامی «تقریبی» نیست.
- **ممیزی شمسی**: `RegisterDatePersian` با الگوی `^1[34]\d{6}$` اعتبارسنجی می‌شود.
- **نام کاربران**: «نام‌خانوادگی + فاصله + نام» مطابق فرمول `ISNULL(LName,'')+' '+ISNULL(FName,'')` در SPها.
- **وابستگی حذف**: دقیقاً همان سه‌گانهٔ CompanyInfoController (استان/شرکت/مخاطب برای کشور؛ شهر/شرکت/مخاطب برای استان؛ شرکت/مخاطب برای شهر).

## ۷) چگونه اجرا کنیم

```bash
npm run test            # واحد + یکپارچه‌سازی
npm run test:unit       # فقط واحد (~۰.۵s)
npm run test:integration# فقط یکپارچه‌سازی (spawn خودکار سرور و DB — ~۱۵s)
npm run test:e2e        # مرورگر Chromium (سرور خودکار — ~۱ دقیقه)
```

هیچ‌کدام به سرور روشنِ دستی یا دیتابیس توسعه نیاز ندارند. سرور توسعهٔ هم‌زمان روی پورت ۳۰۰0 مشکلی ایجاد نمی‌کند (distDir جدا).
