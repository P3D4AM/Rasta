# رستا (Rasta)

> **سامان کار، رونق کسب‌وکار** — سامانه مدیریت ارتباط با مشتری (CRM) مدرن، سبک و فارسی‌محور (RTL-First)

رستا بازنویسی کامل و امروزیِ محصول قدیمی **CRMIdeal 3.1.18.187** (ASP.NET MVC 5 / .NET Framework 4.7) با یک پشته سبک و یکدست است — بدون هیچ‌یک از بارهای میراثی نسخه قبل (۹ نسخه موازی jQuery، دو نسل Kendo UI، مهاجرت ناتمام Bootstrap و…).

## وضعیت

🚧 **فاز ۱ (هسته CRM) و فاز ۲ (انبار و خرید) آماده و تست‌شده‌اند:**
- فاز ۱ — ورود و نقش‌ها، داشبورد، شرکت‌ها، مخاطبین، فرصت‌های فروش (کانبان)، فعالیت‌ها، کارتابل وظایف، محصولات، پیش‌فاکتور → فاکتور، پرداخت‌ها، کاربران و ماتریس دسترسی، گزارش‌ها
- فاز ۲ — انبارها، موجودی و گردش کالا (رسید ورود/حواله خروج/انتقال/اصلاح)، کارت کالا، سفارشات خرید (سفارش → دریافت کالا) و اتصال خودکار صدور/لغو فاکتور فروش به موجودی انبار
- فاز ۳ — مالی (خزانه/بانک‌داری/پرداخت آنلاین) و فاز ۴ (پروژه‌ها/تعاریف/کاربران بازسازی‌شده از سورس واقعی) — هر دو E2E تست‌شده

### 🆕 بازسازی عیناً اسکیمای دیتابیس (فاز ۴.۵)

اسکیمای رستا از کاتالوگ خود محصول (CRMTabel.ssdl — ۶۳۳ جدول) **عیناً** بازسازی شد:
- **۳۹۶ جدول فیزیکی** با نام و ساختار اصلی CRMIdeal (۳۸۰ جدول اصلی + مدل‌های فعال اپ)
- ۲۶ جدول فعال اپ با @@map/@map دقیق روی نام اصلی (Users/CrmCompany/CrmProjects/...) و تکمیل **۱۰۶۳ ستون اصلی** بدون کم‌وکاست — صحت‌سنجی خودکار با اسکیمای SSDL
- ۳۵۴ مدل کاتالوگ برای همه ماژول‌ها: WS* فروش/انبار، پیامک، ایمیل، تلگرام، کال‌سنتر، پیام داخلی، حضورغیاب، فرم‌ساز، نظرسنجی، اتصال ۲۲ سامانه حسابداری و...
- سند مرجع: `docs/analysis/02-original-db-catalog.md` — کاتالوگ کامل ۶۳۳ جدول + ۳۴۳۸ SP

## پشته فناوری

| لایه | انتخاب |
|---|---|
| زبان | TypeScript (سرتاسر استک) |
| فریم‌ورک | Next.js 16 (App Router) + Route Handlers |
| دیتابیس | Prisma ORM — SQLite (توسعه) → PostgreSQL (استقرار) |
| UI | Tailwind CSS 4 + shadcn/ui — RTL، فونت وزیرمتن، تم زمردی |
| نمودار | Recharts |
| احراز هویت | JWT (jose) + کوکی HttpOnly + scrypt |
| تقویم | جلالی بومی |

## ساختار مخزن

| مسیر | توضیح |
|---|---|
| `src/` | کد اپلیکیشن رستا |
| `prisma/` | اسکیمای دیتابیس + داده دموی فارسی |
| `docs/` | تحلیل نسخه قدیمی، نقشه راه، اسکرین‌شات‌ها |
| `project-analysis/decompiled/` | سورس C# دیکامپایل‌شده نسخه قدیمی (~۹ هزار فایل) — **صرفاً مرجع داخلی پورت ماژول‌ها** |
| `worklog.md` | گزارش کار و تصمیمات پروژه |
| `scripts/` | ابزارهای کمکی توسعه |

## سیاست شاخه‌ها

- 🔒 `main` — خط انتشار؛ فقط پس از تأیید مالک پروژه از `develop` ادغام می‌شود.
- 🛠️ `develop` — **خط فعال توسعه؛** تمام تغییرات از ابتدا فقط روی این شاخه کامیت و پوش می‌شوند تا مالک پروژه انتشار اولیه را تأیید کند.

## اجرا در محیط توسعه

```bash
bun install          # یا npm install
npx prisma generate
npm run db:push      # ساخت دیتابیس توسعه (SQLite)
bun prisma/seed.ts   # داده دمو (بدون bun: npx tsx prisma/seed.ts)
npm run dev          # http://localhost:3000
```

**ورود دمو:** `admin / admin123` (به‌همراه manager و دو کاربر فروش)

## امنیت

- 🔐 رمزنگاری/لایسنس‌گذاری محصول طبق تصمیم مالک، **بعد از انتشار اولیه** تقویت می‌شود.
- رازها در `.env` محلی نگهداری می‌شوند و **هرگز کامیت نمی‌شوند** (الگوی آماده: `.env.example`).
- بدهی‌های امنیتی نسخه قدیمی (ELMAH بدون احراز هویت، `debug=true`، machineKey ثابت و…) در رستا از روز اول برطرف شده‌اند.
