# رستا — نسخهٔ توسعه‌ای ویندوز (Rasta Dev Release)

این بسته برای بررسی دستی قابلیت‌های پیاده‌سازی‌شدهٔ رستا توسط مالک پروژه ساخته شده است.
نسخهٔ برنامه و کامیت مبنا در فایل `VERSION.txt` ثبت شده است. فهرست صادقانهٔ قابلیت‌ها در `FEATURE-STATUS.md`.

---

## ۱) پیش‌نیازها

- **ویندوز ۱۰ یا ۱۱** (۶۴ بیتی)
- **هیچ نرم‌افزار دیگری لازم نیست.** Node.js و دیتابیس و همهٔ وابستگی‌ها داخل خود بسته هستند (`runtime\node.exe` + دیتابیس SQLite).
- دسترسی مدیر (Administrator) لازم نیست.
- اتصال اینترنت لازم نیست (به‌جز پرداخت آنلاین که ذاتاً اینترنت می‌خواهد).

---

## ۲) اجرای برنامه — ساده‌ترین راه

۱. پوشهٔ `Rasta-Dev-Windows` را در یک مسیر دلخواه قرار دهید (مثلاً `C:\Rasta` یا دسکتاپ).
   ⚠️ اگر مسیر **فارسی/عربی** دارد، ممکن است برخی ابزارها مشکل کنند؛ ترجیحاً مسیری با حروف انگلیسی انتخاب کنید (فاصله در مسیر مجاز است).

۲. روی **`Start-Rasta.bat`** دوبار کلیک کنید.

۳. پنجرهٔ آبی PowerShell باز می‌شود، پیش‌نیازها بررسی و سرور اجرا می‌شود؛ سپس **مرورگر خودکار** روی `http://127.0.0.1:3000` باز می‌شود.

۴. ورود:
   - مدیر سیستم: **admin / admin123**
   - سایر حساب‌ها: manager/manager123 · sales1/sales123 · sales2/sales123

> اگر ویندوز هنگام اجرا پیام امنیتی (SmartScreen) نشان داد: «More info» → «Run anyway». این پیام به‌دلیل نداشتن امضای تجاری است.

### اجرای جایگزین (PowerShell)

```powershell
cd <مسیر بسته>
.\Start-Rasta.ps1                 # اجرای عادی
.\Start-Rasta.ps1 -Port 3005      # روی پورت دلخواه
.\Start-Rasta.ps1 -NoBrowser      # مرورگر باز نشود
.\Start-Rasta.ps1 -ResetDb        # بازنشانی دیتابیس آزمایشی به دادهٔ اولیه (با تأیید و پشتیبان)
```

اگر PowerShell اجرای اسکریپت را بست (ExecutionPolicy)، از `Start-Rasta.bat` استفاده کنید که خودش سیاست را دور می‌زند.

---

## ۳) توقف برنامه

```powershell
.\Stop-Rasta.ps1
```

**توجه:** بستن پنجرهٔ اسکریپت، برنامه را متوقف نمی‌کند — سرور در پس‌زمینه می‌ماند. برای توقف حتماً `Stop-Rasta.ps1` را اجرا کنید.

---

## ۴) فایل‌ها و پوشه‌ها

| مسیر | شرح |
|---|---|
| `Start-Rasta.bat` / `Start-Rasta.ps1` | اجرای برنامه (رابط ساده / کامل با پارامتر) |
| `Stop-Rasta.ps1` | توقف برنامه |
| `Install-Rasta.ps1` | (اختیاری) بررسی سلامت بسته + ساخت میان‌بر دسکتاپ |
| `app\` | فایل‌های برنامه (خروجی production برنامهٔ Next.js) |
| `runtime\node.exe` | Node.js نسخهٔ ۲۴ LTS — فقط برای اجرای رستا؛ چیزی در ویندوز نصب نمی‌کند |
| `data\rasta.db` | **دیتابیس آزمایشی شما** — مستقل و جدا از هر محیط توسعه؛ داده‌های شما بعد از بستن برنامه می‌ماند |
| `seed\rasta-seed.db` | نسخهٔ پاک اولیهٔ دیتابیس (دادهٔ نمونه) — فقط در اولین اجرا یا `-ResetDb` استفاده می‌شود |
| `logs\` | لاگ‌های اجرا و خطا (`rasta-<تاریخ>.out.log` و `.err.log`) |
| `.env` | پیکربندی محلی (پورت، مسیر دیتابیس، راز امضای ورود) — در اولین اجرا خودکار ساخته می‌شود |
| `.env.example` | نمونهٔ مستند پیکربندی |
| `FEATURE-STATUS.md` | فهرست کامل قابلیت‌ها، محدودیت‌ها و روش آزمایش دستی |
| `TROUBLESHOOTING-FA.md` | خطاهای رایج و راه‌حل |

---

## ۵) نکات مهم

- **داده‌های شما ایمن است:** اسکریپت اجرا هرگز دیتابیس موجود را پاک نمی‌کند. بازنشانی فقط با `-ResetDb` و بعد از تأیید شما انجام می‌شود و از دادهٔ قبلی پشتیبان می‌گیرد.
- **دسترسی از شبکه بسته است:** برنامه فقط روی `127.0.0.1` گوش می‌دهد؛ از سایر رایانه‌های شبکه قابل دسترسی نیست.
- **اطلاعات محرمانه در بسته نیست:** فایل `.env` با راز تصادفیِ تولیدشده روی همان سیستم ساخته می‌شود؛ هیچ رمز/کلید واقعی داخل بسته نیست (رمز حساب‌های آزمایشی نمونه است).
- **این نسخهٔ توسعه‌ای است:** نسخهٔ تکمیل‌شدهٔ محصول نیست؛ فهرست دقیق چیزهایی که هست و نیست در `FEATURE-STATUS.md`.

---

## ۶) اگر فایل ZIP ندارید و می‌خواهید خودتان بسازید

ساخت این بسته در مخزن پروژه با `release/build-release.mjs` مستند و تکرارپذیر است (جزئیات فنی در همان فایل).
